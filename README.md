Objective

Creating an easy-to-use web application that would help users convert temperatures from 
one unit to another by providing them with their equivalents in Celsius, Fahrenheit, and Kelvin.

Tools & Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git & GitHub

Structure of Project

- index.html - Interface for users
- style.css - Styling along with animations
- script.js - JavaScript code for performing conversions

Performed Tasks

- Designing of interface of the temperature converter.
- Creation of input boxes and unit choices.
- Implementation of conversion formulas in JavaScript code.
- Validating inputs entered by users.
- Making the interface responsive with the help of animations.

Output

A responsive temperature conversion tool developed that can convert temperatures among various 
scales.
